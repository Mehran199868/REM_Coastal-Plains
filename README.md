# REM_Coastal-Plains
README
======

Overview
--------
This dataset accompanies the study on the Referenced Empirical Ground Motion 
Model for the Coastal Plains Region of the United States. It contains the 
combined dataset used in the regression and the estimated adjustment-factor 
coefficients and aleatory standard deviations.

File descriptions
-----------------

1. Combined_Flatfile

   This file contains the combined dataset used in the regression analysis.
   It was compiled from three independent datasets: Goulet et al. (2014),
   Chapman and Guo (2021), and Thompson et al. (2023).

2. Adjustment_Coefficients

   This file contains the estimated adjustment-factor coefficients and
   aleatory standard deviations obtained from the mixed-effects regression.
   The coefficients should be used with the corresponding model equations
   and definitions provided in the accompanying manuscript.

Use and interpretation
----------------------
Refer to the accompanying manuscript for the data-selection criteria,
regression methodology, model equations, and definitions of the aleatory
variability components. Apply the coefficients using the units and
logarithmic conventions specified in the manuscript.

Citation
--------
When using these files, cite the accompanying manuscript, this dataset
using its repository DOI, and the relevant original data sources:
Goulet et al. (2014), Chapman and Guo (2021), and Thompson et al. (2023).
